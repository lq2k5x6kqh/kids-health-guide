# 我院多学科联合门诊开诊：整合优质医疗资源，让患者“一站式”精准就医！

> 更新时间：2026-09-17 (UTC+8)

**MDT**

/ **血液透析通路多学科联合门诊** /

11月3日上午，在伍家院区血液净化中心主任宋志霞的牵头带领下，由血液净化中心副主任医师饶毅峰、血管外科主治医师孙建锋和放射影像科主治医师宋继华等专家团队共同坐诊的血液透析血管通路多学科联合门诊正式开诊，**开诊首日便迎来了3位亟需解决血管通路问题的血液透析患者。**

廖先生（化名）是开诊后的首位就诊患者。他是一位维持性血液透析长达10年之久的尿毒症患者，由于自身血管条件不佳，他的透析之路颇为曲折，在经历了自体动静脉内瘘术和静脉留置导管术后，在透析的第3年进行了移植血管内瘘术维持血液透析治疗。
然而，好景不长，近两年来移植血管的并发症逐渐显现，动脉瘤、血管狭窄、渗血以及血管疼痛等问题接踵而至，让廖先生苦不堪言。他曾多次就诊寻求通路解决办法，但都无功而返。在得知市中心人民医院多学科联合门诊即将开诊的消息后，他立即预约挂号，并于开诊当日早早前往等待就诊。
联合门诊专家团队在详细了解他的病史、症状和相关检查结果后，予以血管超声辅助检查，对血管通路的异常进行评估和诊断，并开展了深入的研究和探讨，最终制定出了明确的个体化治疗方案。廖先生对于本次高效、快捷的就诊体验赞不绝口。
**/ ****血液净化中心主任宋志霞 /**

宜昌市中心人民医院伍家院区

血管通路是血液透析患者赖以生存的“生命线”，随着尿毒症患者透析龄的延长，透析通路的并发症也越来越多，越来越复杂，同时通路的长期使用也让患者面临着血管资源不断耗竭、透析生命线被迫切断的残酷难题。通过开设多学科联合门诊，不同学科的专家共同协作和交流，整合不同领域的优质资源，既促进了医疗团队之间的合作，为患者提供了更全面、个性化的医疗服务，确保患者能够获得最佳的治疗效果，充分满足患者的诊疗需求。

**MDT**

/ **减重塑形多学科联合门诊** /

11月8日下午，多学科联合减重塑形门诊在西陵院区正式开诊，西陵院区临床营养科主任郑军，普外科主任全昌银、副主任医师胡回忆，内分泌科副主任医师朱丽、康复医学科主治医师丁玲、中医科主治医师肖开婷等相关学科专家联合出诊，为患者提供综合减重方案。**减重门诊开诊首日接诊了8位患者，均为30至50岁年龄段的女性。**

48岁的郑女士（化名）是该门诊接诊的首位患者。“因为平时工作较忙，很少运动，但是我在饮食上非常注意，每顿吃得并不多，但体重始终减不下来。”郑女士说，因为太胖了穿衣服不好看，步行稍微走远一点也很累，平时回家爬到三楼就有点气喘。
经测量郑女士身高1米55、体重72.5公斤，计算体重指数是30.2kg/m2,诊断为肥胖。医生将郑女士带到人体成分分析仪前进行测量。大概两分钟后，测量数据出炉。在人体成分分析表格上包含了体重、体重指数、脂肪重量、体脂率、内脏脂肪面积、肌肉重量、细胞内水分等多项指标，可以判断出脂肪超重多少，需要减多少公斤脂肪，复查后可以很好的评估减重效果。
接着，通过专家联合问诊，为患者进一步排除了相关疾病导致的继发性肥胖，经反复商讨，为郑女士制定了穴位埋线、控制总热量、增加蛋白质摄入的科学饮食减重方案，并为患者制定了个性化一周减重食谱。
**/ ****临床营养科主任郑军 /**

宜昌市中心人民医院西陵院区

肥胖不仅仅是外形问题，更是一种疾病，与冠心病、高脂血症、高血压、2型糖尿病、癌症等一系列疾病相关，每年因超重、肥胖引起的相关疾病逐年增加，减重成为了许多患者的迫切需求。为让更多市民了解到肥胖的危害，使用科学的方法减重，医院整合多学科优势资源，由临床营养科牵头，开设多学科联合(MDT)减重门诊，旨在提高诊疗质量，为肥胖患者提供更全面、精准及个体化的诊疗方案。

**/ ****副院长赵卫民 /**

宜昌市中心人民医院党委委员

近年来，为解决特殊疾病患者群体急难愁盼的就医问题，医院整合优质医疗资源、创新服务模式，先后开设了甲状腺、乳腺结节、肿瘤、儿童生长发育、生殖等10余个多学科联合(MDT)门诊。针对某一疾病，由多个科室专家组成一个团队，以联合会诊的形式，通过多学科讨论，综合各方意见，共同为患者制定最佳的治疗方案，为患者提供专业化、个体化、规范化和全方位的“一站式”精准诊疗服务，实现了学科医疗资源的最大化整合，提高了医疗质量和效率，大大改善了患者的就医体验。
